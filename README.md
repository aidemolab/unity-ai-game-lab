# Unity AI Game Lab

A professional development lab for exploring AI-assisted game creation in Unity.

## Project purpose

This private repository will contain the Unity project, source code, configuration, documentation, and controlled development history for the Unity AI Game Lab.

The project will be developed incrementally, with each milestone reviewed and tested before it is committed to the `main` branch.

## Development workflow

| Component | Responsibility |
| --- | --- |
| ChatGPT | Architecture, project management, and technical coaching |
| Codex | Primary software engineering and GitHub operations |
| GitHub | Source of truth and version history |
| MCP for Unity | Controlled bridge between AI tools and the Unity Editor |
| Unity | Game development, testing, and deployment |

## Technology

- Unity 6
- C#
- Git and GitHub
- MCP for Unity
- Windows and Web build targets

## Repository principles

- Keep generated Unity cache and build files out of version control.
- Commit small, meaningful, tested changes.
- Document important architectural and tooling decisions.
- Use external repositories only as clearly attributed references and in accordance with their licences.
- Never commit API keys, access tokens, credentials, or other secrets.
